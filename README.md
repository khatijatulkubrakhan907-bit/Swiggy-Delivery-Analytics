A real-world Data Analytics project inspired by Swiggy operations, built using **Python, SQL, Power BI, and Data Science**.

## Tech Stack

* Python
* SQL
* Power BI
* Pandas
* Matplotlib
* Plotly

Analyze delivery delays, customer ratings, traffic impact, weather conditions, and restaurant performance to generate business insights.
